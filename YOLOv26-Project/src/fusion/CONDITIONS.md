# 点云后融合（B2）· 适用条件与已知局限

> 与 `late_fusion.py` 同目录的工程说明。更新：2026-10-15（加密网格验证后修订）

## 一句话

结果级后融合：YOLO 只做 2D 检出 → mask/框投影筛点 → 统计滤波 → 平面拟合 → 米制量算。
纯图像只能给像素，融合后给米 / ㎡。**融合相对纯图像的优势只在"深度未知或非平面"时成立**；
在"理想平面 + 已知恒定拍摄距离"下，纯图像像素换算（mask 像素 × mpp）本身就很准（<3%），融合并不更准。

## 适用条件

1. **构件近似平面**：`fit_plane` + 凸包面积假设病害落在平面上（桥面、墙面成立；墩柱曲面、梁侧棱角处有系统偏差）。
2. **相机参数已知**：K/R/t 来自仿真导出；真实场景需标定 + 配准，标定误差会 1:1 传导到米制结果。
3. **点云密度决定面积精度**：凸包顶点只能落在实际点位上，网格点相对真边缘内缩约半个格距。
   2026-10-15 十场景实测（真值mask直喂）：20mm 网格剥落低估约 16~23%（与理论 `(1-((r-0.01)/r)²)` 吻合）；
   10mm 网格（12万点）→ 剥落均值 15.9%、坑洞 14.8%（坑深非平面另有贡献）。裂缝长度（PCA 极差）
   对密度不敏感，粗/密网格下均值 3~4%。继续加密可再压面积误差，但边际递减。
4. **检出是前置瓶颈**：融合只负责"量得准"，不管"找得到"。仿真场景存在 sim2real 检出 gap
   （第一轮 s 在仿真裂缝上漏检；hole 类仿真圆盘零检出）——验证时检出与测量分开统计。

## 已知局限（答辩问到直接认）

1. 全部定量验证在 Blender 理想场景（参数已知、2mm 高斯噪声、无标定误差）；真实场景误差一定更大。
2. 仿真样本 10 组（sample01~10，其中 04~10 含坑洞真值；01~03 为早期稀疏网格版，04~10 为 12 万点密网格版）。
   统计量仍小；结论"裂缝~3%、面积类~15%"是工程可用性陈述，不是统计保证。
3. hole 类融合只有仿真验证、无真实权重检出支撑（YOLO hole 训的是路面坑洞，认不出仿真灰盘）。
4. 深度突变区（坑沿）平面拟合会把边缘点拉偏，面积取凸包是外包络估计。
