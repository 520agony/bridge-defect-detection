## 四、关键性能指标（申报书要求）

- 推理速度：**30 FPS**（Jetson / TensorRT / INT8）
- 模型大小：**≤ 50 MB**（量化后）
- 数据划分：95% / 5%（训练/测试）

## 五、建议顺序

1. 640 基线跑完 → 天花板数字
2. 960 解决 hole/corrosion 小目标 → mAP 提升
3. Grad-CAM + 混淆矩阵 → 论文配图
4. ONNX/TensorRT 导出 + 量化 → 30FPS 指标
5. Web 平台 → 结题可展示成果
6. LiDAR 融合 → 视时间/硬件，否则作为「未来工作」
