## 2. 标注格式

使用 **YOLO 格式**：每张图对应一个同名的 `.txt` 文件

```
每行一个目标：class_id center_x center_y width height
所有值归一化到 [0, 1]
```

示例：
```
0 0.5234 0.6187 0.2341 0.0892    ← 一条裂缝
1 0.7654 0.3512 0.1567 0.1234    ← 一处剥落
```

---

## 3. 五个类别

| ID | 类别名 | 英文名 | 标注说明 |
|----|--------|--------|----------|
| 0 | 裂缝 | crack | 直线或曲线状深色纹路，框紧贴裂缝 |
| 1 | 剥落 | spalling | 混凝土表面脱落区域，框住脱落范围 |
| 2 | 露筋 | rebar_exposed | 锈蚀钢筋外露，框住露筋区域 |
| 3 | 渗水 | water_seepage | 潮湿/水渍区域，框住湿润范围 |
| 4 | 正常 | normal | 完好无损的桥面/桥墩区域 |

---

## 4. 标注规则

### 框选原则
- 框紧贴目标边缘，留白不超过 2 像素
- 遮挡超过 50% 的不标
- 目标小于 10x10 像素（模糊不清）不标
- 多条裂缝交叉时，分别单独框选

### 裂缝标注（最重要）
- 沿裂缝走向框选，框的宽度覆盖裂缝+两侧各1-2mm
- 必须在照片旁边放参照物（硬币/卷尺）

### 负样本
- "正常"类别的图片中**不放标注框**
- 至少要有 200 张正常无病害的图片

## 5. 拍照规范

### 必须注意
| 项目 | 要求 |
|------|------|
| 光线 | 自然光，不逆光，不用闪光灯 |
| 角度 | 正对病害（垂直拍摄） |
| 参照物 | 裂缝图必须放硬币或卷尺 |
| 距离 | 离病害 30cm~1m，保证清晰 |
| 背景 | 尽量纯桥面，不拍杂物/人影 |
| 分辨率 | 不低于 1280x720 |

### 拍摄数量建议
| 类别 | 最少数量 | 理想数量 |
|------|----------|----------|
| 裂缝 | 300 张 | 500+ |
| 剥落 | 200 张 | 300+ |
| 露筋 | 200 张 | 300+ |
| 渗水 | 100 张 | 200+ |
| 正常 | 200 张 | 300+ |
| **总计** | **1000 张** | **1600+** |

---

## 6. 数据集划分

按 **7:1.5:1.5** 比例随机分：

```
datasets/
  images/train/  ← 700 张（训练集）
  images/val/    ← 150 张（验证集）
  images/test/   ← 150 张（测试集）
```

---

## 7. 标注文件命名

统一格式：
```
{场景}_{桥名}_{序号}.jpg
{场景}_{桥名}_{序号}.txt

示例：
pier_ganjiang_001.jpg  →  pier_ganjiang_001.txt
deck_bayi_002.jpg       →  deck_bayi_002.txt
beam_aihu_003.jpg       →  beam_aihu_003.txt
lab_normal_004.jpg      →  lab_normal_004.txt  (负样本，txt 为空文件)
```
