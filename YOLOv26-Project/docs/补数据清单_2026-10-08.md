# 补数据清单（2026-10-08）

> 背景：5 类近景域（桥梁/混凝土/路面）YOLO 分割。本轮目标：修正短板类（孔洞/露筋/泛碱），提高独立样本量与多样性。
> 依据：wash 独立测试集评测（rebar mask mAP≈0.20-0.24、efflo≈0.20 为短板）+ 本轮数据审查发现（hole 拼图/重复多）。

## 一、缺口分析

| 类别 | 现状 | 问题 | 建议补充量 |
|------|------|------|-----------|
| hole 孔洞（路面坑洞） | 训练仅 **588 张图（清理后）** | 原来源约半数是拼图/水印/新闻图（已清理），独立样本严重不足 | **1500~3000 张**，单张、多边形 |
| rebar_exposed 露筋 | 4471 张但 17% 实例占图<0.1% | 小目标最难，wash mAP 最低 | **1000~1500 张**，嵌套/含上下文场景 |
| efflorescence 泛碱 | 5591 张 | wash mAP 低 | **800~1500 张 + 500 张干净负样本** |
| spalling 剥落 | 6527 张 | 中游（0.43） | 可选 500~1000 张 |
| crack 裂缝 | 12551 张 | 够用 | 不补 |

**硬性要求**：YOLOv8/COCO **Segmentation**（polygon，紧贴病害）；不要 bbox/Detection；不要新闻截图、拼图、带大字水印图库图；近景/中近景；短边 ≥960px（640 可接受但欠佳）；4 点矩形=假 mask 会毒害训练。

## 三、已下载两个 pothole zip 的验收结论（`当前所需要的数据/`）

### zip0：`pothole project.v1i.coco-segmentation.zip`（621 张，150MB）
- ✅ 标注：真 polygon（中位 12 点），COCO Segmentation 格式
- ⚠ 类别乱：6 个类（Potholes/Pothole/high/low/medium/object，混严重度子类）→ 需要折叠为单类 hole
- ⚠ 混入新闻截图（Detroit 坑洞报道）、施工泥地、行车记录仪画面；分辨率 402px~4032px 参差
- **结论：可用，需清洗（去截图/低质/非路面），预计可用 ~300~450 张**

### zip1：`Potholes and Roads Instance Segmentation.v1i.yolov8.zip`（1355 张，134MB）
- ⚠ **标注混格式**：一部分行只有 bbox（5 列），一部分是 polygon —— 不是纯 seg 导出
- ⚠ 大量行车记录仪视频帧（带速度/GPS/时间 OSD 文字叠加），少量近景；有眩光帧
- **结论：只保留 polygon 行 + 剔 OSD/眩光/低质帧，预计可用 ~500~800 张**

## 四、下载后的合流流程（我来做）
1. 新数据放 `YOLOv26-Project/新补充数据/`（zip 原样）
2. 我复用 `build_clean5` + `wash_independent_test` 的去重/清洗管线：
   统一转 YOLO-seg → 剥矩形/短多边形 → 与 clean 全量去重（md5+dHash）→ 并入 train/val
3. 更新配置后开云训（s / m / distill 三轮）
