## 历史经验（避免重蹈覆辙）

| 教训 | 应对 |
|------|------|
| 主干 bbox→rect 假 mask 毒害 seg 训练（v1/v2 阶段）| **已彻底清矩形**，新数据走 build_clean_dataset.py 自动剥 |
| 近景腐蚀域漂移（v3 阶段）| 找新数据要严格**航拍视角** |
| v2 seg 训练被 OOM 截断 | train_seg.py batch 6 + overlap_mask=False |
| 关 cmd 训练被 window-CLOSE 杀掉 | 用 Claude 后台任务，进程不挂控制台 |
| 断电丢进度 | train_seg.py --resume 自动从 last.pt 续 |
| 24GB 数据盘不够 | 数据集（datasets/）+ 训练实验（experiments/）都在大磁盘目录 |

## 训练监控建议

- 每 1-2 小时看 `experiments/seg_v2_clean/results.csv` 确认 mAP 还在涨
- patience 30 触发后说明收敛，跑评估
- 训练完看每类 mask mAP，**crack > 0.85** 是 v2 模型的目标（v3 训练时是真 polygon，可以冲 0.9）
