# 项目进度与交接（2026-08-22 更新）

> 项目：智巡飞眼—基于 YOLOv26 与点云融合的无人机桥梁病害全场景检测与评估模型（国家级大创）

## 当前完成状态

### 检测模型（已完成，定为最终版）
- 模型：**yolov8s**（标准架构，无 P2 等改动），22.5MB（满足 ≤50MB）
- 权重：`experiments/yolov26_baseline_v2/weights/best.pt`
- **mAP50 = 0.424（标准）/ 0.430（TTA）**
- 数据：**7 类**（最终版 `datasets/final_7class/`，33585 张）
  - crack 0.77 / rebar_exposed 0.53 / seepage 0.40 / honeycomb 0.40 / spalling 0.36 / corrosion 0.26 / hole 0.25

### 改进尝试结论（都试过了，不用再试）
| 方法 | 结果 |
|------|------|
| 数据清理 8类→7类 | ✅ 0.399→0.424（唯一有效） |
| P2 检测头 | ❌ 0.357（失败，已放弃） |
| 960 分辨率 | ➖ 0.421（打平，已放弃） |
| TTA（augment=True） | ✅ +0.6 点（白捡，交付时用） |

> 结论：小目标（孔洞/锈蚀/剥落，框占图 0.2%~0.8%）是数据本质决定的硬骨头，P2/960/TTA 都撼动不了。**决定不磕 mAP，0.43 收尾。**

## 阶段二（病害量化分析，2026-08-22 ✅ 已完成）
- 新增 `src/analysis/` 包：`measure.py` / `grade.py` / `report.py` / `quantify.py` + CLI
- **测量**：裂缝用骨架化 + 距离变换测宽长（宽 = 2×距离 − 1；合成图验证奇数宽度精确、偶数差 1px、长度正确）；其余类用 bbox 面积/直径代理
- **等级评估**：7 类全（扩展了 honeycomb/hole/seepage/corrosion 规则）；`--px-per-mm` 标定转 mm 出正式等级，无标定给像素级相对严重度 + `needs_calibration`
- **报告**：JSON + Markdown（检测明细表 + 处置建议 + 标定说明）
- **CLI**：`python -m src.analysis.quantify --source 图/目录 --weights best.pt [--px-per-mm N]`
- **已知限制**：模型只出 bbox（无分割 mask），低对比度发丝裂缝阈值提取不可靠，报告已标注「低质量估算」或需标定

## 待办：数据增强重训（提升小目标 mAP，用户找数据中）
- **目标**：corrosion(0.26) / hole(0.25) / spalling(0.36) 三类小目标加数据重训，尽可能拉高 mAP
- **分析结论（2026-08-22，见 `src/analysis/data_stats.py`）**：尺寸与 mAP 强相关
  - crack 中位占图 18.5% → 0.77；corrosion 0.21% → 0.26；hole 0.50% → 0.25；spalling 0.80% → 0.36
  - 例外：rebar_exposed 0.29%（很小）→ 0.53，因露筋视觉特征独特
- **新数据要求**：三类中位占图 ≥1~2%（现在 0.21~0.80%）；标注口径一致（hole/corrosion/spalling 易混）；特写:无人机视角 ≈ 1:1 防域漂移
- **增强**：train_final.py 已加 `--copy-paste`(建议 0.1~0.3) / `--mixup` / `--scale` / `--data` / `--name` 参数
- **工具**：`python -m src.analysis.data_stats --labels <新数据labels> --classes ...` 检验新数据尺寸分布
- **预期**：总 mAP 0.424 → 0.45~0.50；三类 0.25~0.36 → 0.35~0.50
- **流程**：新数据到位 → data_stats 核对尺寸 → 5 轮冒烟 → 300 轮正式（`--copy-paste 0.2 --mixup 0.1 --scale 0.7`）
