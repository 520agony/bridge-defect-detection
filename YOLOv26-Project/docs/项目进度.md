## 当前完成状态

### 检测模型（已完成，定为最终版）
- 模型：**yolov8s**（标准架构，无 P2 等改动），22.5MB（满足 ≤50MB）
- 权重：`experiments/yolov26_baseline_v2/weights/best.pt`
- **mAP50 = 0.424（标准）/ 0.430（TTA）**
- 数据：**7 类**（最终版 `datasets/final_7class/`，33585 张）
  - crack 0.77 / rebar_exposed 0.53 / seepage 0.40 / honeycomb 0.40 / spalling 0.36 / corrosion 0.26 / hole 0.25

### 改进尝试结论（都试过了，不用再试）
| 方法 | 结果 |
|------|------|
| 数据清理 8类→7类 | ✅ 0.399→0.424（唯一有效） |
| P2 检测头 | ❌ 0.357（失败，已放弃） |
| 960 分辨率 | ➖ 0.421（打平，已放弃） |
| TTA（augment=True） | ✅ +0.6 点（白捡，交付时用） |

> 结论：小目标（孔洞/锈蚀/剥落，框占图 0.2%~0.8%）是数据本质决定的硬骨头，P2/960/TTA 都撼动不了。**决定不磕 mAP，0.43 收尾。**

### 训练计划（结合改进经验：P2/960 无效，数据是关键杠杆）
**配方**（沿用验证过的）：yolov8s + 640 + 300轮 + AdamW(lr0=0.001) + cos_lr + warmup3 + dropout0.1 + close_mosaic15

**消融三步**（隔离数据 vs 增强的效果）：
| 实验 | 数据 | 增强 | 目的 |
|------|------|------|------|
| Exp0 基线 | final_7class | 原配置 | 已有 0.424 |
| Exp1 仅数据 | final_7class_v3 | 原配置 | 看新数据效果 |
| Exp2 数据+增强 | final_7class_v3 | +copy_paste 0.2 +scale 0.7 +mixup 0.1 | 看增强叠加效果 |

**命令**：
```bash
# Exp1（仅数据）
./.venv/Scripts/python.exe src/train/train_final.py --train --data configs/data_final_v3.yaml --name yolov26_v3_data
# Exp2（数据+增强）
./.venv/Scripts/python.exe src/train/train_final.py --train --data configs/data_final_v3.yaml --name yolov26_v3_aug --copy-paste 0.2 --mixup 0.1 --scale 0.7
```

**评估**：盯每类 AP（尤其 corrosion/spalling/honeycomb），最后加 TTA（+0.6）
**预期**：总 mAP 0.424→0.45~0.50；corrosion 0.26→0.40+；spalling/honeycomb →0.45~0.55；**hole 因无数据预计难涨**
**风险**：新数据偏特写（防域漂移已靠保留原数据摊薄）；hole 是本次未解决短板
