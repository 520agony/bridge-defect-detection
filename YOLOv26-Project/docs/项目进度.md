## 当前完成状态

### 检测模型（已完成，定为最终版）
- 模型：**yolov8s**（标准架构，无 P2 等改动），22.5MB（满足 ≤50MB）
- 权重：`experiments/yolov26_baseline_v2/weights/best.pt`
- **mAP50 = 0.424（标准）/ 0.430（TTA）**
- 数据：**7 类**（最终版 `datasets/final_7class/`，33585 张）
  - crack 0.77 / rebar_exposed 0.53 / seepage 0.40 / honeycomb 0.40 / spalling 0.36 / corrosion 0.26 / hole 0.25

### 改进尝试结论（都试过了，不用再试）
| 方法 | 结果 |
|------|------|
| 数据清理 8类→7类 | ✅ 0.399→0.424（唯一有效） |
| P2 检测头 | ❌ 0.357（失败，已放弃） |
| 960 分辨率 | ➖ 0.421（打平，已放弃） |
| TTA（augment=True） | ✅ +0.6 点（白捡，交付时用） |

> 结论：小目标（孔洞/锈蚀/剥落，框占图 0.2%~0.8%）是数据本质决定的硬骨头，P2/960/TTA 都撼动不了。**决定不磕 mAP，0.43 收尾。**

## 数据增强重训（✅ 已定论：接受基线）
- **最终模型 = `yolov26_baseline_v2`（mAP50 0.424 val / 0.381 test）**，训练数据 final_7class（7 类，33585 张）
- **三次实验公平对比（旧 test 集）**：
  | 实验 | 总 mAP50 | 结论 |
  |------|---------|------|
  | 基线 | 0.381 | ✅ 最终版 |
  | v3 加数据（近景+坑洞） | 0.385 | +0.004 无意义；corrosion/honeycomb 反而降 |
  | v4 copy_paste 增强+剔除有害 | 0.377 | 更差；copy_paste 无效，honeycomb 仍降 |
- **定论**：bbox yolov8s + 无人机俯拍已到天花板（~0.38 test）。小目标（corrosion 0.26/honeycomb 0.22/spalling 0.28/hole 0.28）加数据、调增强都救不动
- **唯一有效发现**：hole 加路面坑洞数据 +0.026（可留作后续参考）；近景数据是域漂移（有害）
- 未删除：v3/v4 数据集 + 补充源 zip（留作实验记录，占 ~15GB，可随时清理）
